# 사진 정리 (PhotoCleaner)

아이폰에서 사진을 한 장씩 넘겨보며 빠르게 정리하는 iOS 앱입니다.
화면 하단에는 **안하기** / **삭제하기** 두 개의 버튼만 있습니다.

- **안하기**: 현재 사진을 그대로 두고 다음 사진으로 넘어갑니다.
- **삭제하기**: 현재 사진을 삭제 목록에 담고 바로 다음 사진으로 넘어갑니다.

사진을 모두 넘기면 완료 화면에서 **삭제 실행** 버튼으로 담아 둔 사진을
한 번에 삭제합니다. (iOS 정책상 실제 삭제 시 시스템 확인창이 한 번 표시됩니다.)

## 추가 기능

- **스와이프 제스처**: 사진을 손가락으로 밀어서 넘길 수 있습니다.
  - 왼쪽으로 밀기 → 삭제하기
  - 오른쪽으로 밀기 → 안하기
  - 미는 동안 "삭제" / "안하기" 라벨이 표시되고, 카드가 화면 밖으로 날아갑니다.
- **되돌리기(undo)**: 우측 상단(또는 완료 화면)의 되돌리기 버튼으로 방금 한 동작을
  취소하고 이전 사진으로 돌아갑니다. 삭제 예약도 함께 취소됩니다.
- **진행 상황 표시**: 상단에 `현재 / 전체` 장수와 삭제 예정 장수를 보여줍니다.

## 특징

- SwiftUI + PhotoKit 로 구현
- 매번 확인창을 띄우지 않아 정리가 빠릅니다 (삭제는 마지막에 한 번에 실행)
- 세로 방향, 다크 모드 UI

## 실행 방법

> ⚠️ iOS 앱이므로 반드시 **macOS + Xcode** 환경이 필요합니다. (윈도우/리눅스에서는 빌드 불가)

### 1) 시뮬레이터에서 빠르게 확인

1. macOS 에서 Xcode 16 이상을 설치합니다. (App Store 에서 무료)
2. 이 저장소를 내려받아 `PhotoCleaner/PhotoCleaner.xcodeproj` 를 더블 클릭해 엽니다.
3. Xcode 상단 툴바에서 실행 대상을 `iPhone 15` 같은 **시뮬레이터**로 고릅니다.
4. `⌘R`(또는 ▶︎ 버튼)을 눌러 실행합니다.
5. 앱이 뜨면 **"사진 접근 허용"** 을 누릅니다. 시뮬레이터에는 기본 샘플 사진이
   들어 있어 바로 넘기기/삭제를 확인할 수 있습니다.

### 2) 내 아이폰에 설치해서 실제로 쓰기

1. 아이폰을 케이블로 맥에 연결합니다.
2. Xcode 왼쪽 네비게이터에서 프로젝트(파란 아이콘) → **TARGETS: PhotoCleaner** →
   **Signing & Capabilities** 탭으로 갑니다.
3. **Team** 에서 본인 Apple ID(개인 무료 계정도 가능)를 선택합니다.
4. **Bundle Identifier** 를 세상에 하나뿐인 값으로 바꿉니다.
   예: `com.본인이름.PhotoCleaner`
5. 상단 실행 대상에서 연결한 **내 아이폰**을 선택하고 `⌘R` 로 실행합니다.
6. 처음 설치 시 아이폰에서 **설정 → 일반 → VPN 및 기기 관리** 로 들어가
   본인 개발자 인증서를 **신뢰**해 주세요. (무료 계정은 7일마다 재설치 필요)
7. 앱을 열고 사진 접근을 허용하면 실제 사진으로 정리를 시작할 수 있습니다.

### 조작법 요약

- 화면 하단 **안하기 / 삭제하기** 버튼을 누르거나,
- 사진을 **왼쪽으로 밀면 삭제**, **오른쪽으로 밀면 안하기**,
- 우측 상단 **되돌리기(↩︎)** 버튼으로 방금 동작을 취소,
- 마지막 사진까지 넘기면 **삭제 실행** 버튼으로 담아 둔 사진을 한 번에 삭제.

## 프로젝트 구조

```
PhotoCleaner/
├─ PhotoCleaner.xcodeproj
└─ PhotoCleaner/
   ├─ PhotoCleanerApp.swift      # 앱 진입점
   ├─ ContentView.swift          # 화면 UI (사진 + 하단 버튼)
   ├─ PhotoLibraryManager.swift  # 사진 접근/로드/삭제 로직
   └─ Assets.xcassets
```

## 사진 접근 권한 안내 문구

`Info.plist` 값은 빌드 설정(`INFOPLIST_KEY_*`)으로 자동 생성됩니다.

- `NSPhotoLibraryUsageDescription`: 사진 정리를 위해 사진 접근을 요청합니다.

## 참고

- 실제로 사진을 삭제하려면 실제 아이폰 기기에서 실행하는 것이 가장 정확합니다.
- 삭제된 사진은 iOS의 "최근 삭제된 항목" 앨범에 일정 기간 보관되므로
  실수로 지워도 복구할 수 있습니다.
